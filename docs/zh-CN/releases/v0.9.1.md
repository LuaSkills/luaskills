# LuaSkills v0.9.1 升级指南

本文对应 v0.9.1 开发目标。版本发布后可按文档从仓库下载发行资产或从注册表安装。当前源码使用 Rust **1.99.1**，最低版本与工具链分别记录在 `Cargo.toml` 和 `rust-toolchain.toml`。

## 技能包迁移

| 原用法 | v0.9.1 用法 |
| --- | --- |
| 清单包级或入口级 `help` | 将使用说明迁到 `skills/<指南名>/SKILL.md`，在 `registration.prompt_skills` 中登记。清单兼容读取旧字段，运行时忽略其内容。 |
| 逐个公开工具 | 省略 `registration` 即沿用直接调用，也可声明 `registration.mode: explicit`。附带指南时，支持的宿主可将选定入口切换为隐式调用。 |
| 默认向模型暴露大量工具定义 | 使用 `registration.mode: implicit` 并附带至少一份指南。宿主发布指南并通过自己的调度入口执行动作。 |
| 适配器自行转换公开工具名 | 通过 `RuntimeEntryDescriptor::public_tool_name()` 获取带下划线的公开名称。运行时在构建注册表时拒绝同名冲突。 |

包和每份指南都必须提供 `registration.default_locale` 语言下的非空 `title` 与 `description`。参数约束保留在入口的 `input_schema` 或 `input_schema_file`。打包时将 `skills/` 和清单放在同一个包中。见[开发手册示例](../development/skill-development.md#25-包注册与提示词技能)。

## 宿主与 SDK 迁移

- Rust 宿主通过 `list_entries_for_authority` 查询可见入口，通过 `list_skill_registrations` 取得可见的注册声明。隐式调用将原始入口描述传给 `call_implicit_skill`，由运行时复核当前生效的包实例，并在进入 Lua 前按已编译的 Schema 校验参数。
- 历史 C 与 JSON FFI 帮助符号仍有导出。合法请求会收到包帮助已停用的错误。FFI 和 SDK 仍可通过 `list_entries` 和 `call_skill` 发现、调用直接工具。上文的注册查询与隐式调用为当前源码的 Rust API。模型工具、指南命名、渲染与授权由宿主控制。
- 指南文件地址属于宿主元数据。面向模型的目录只提供指南名和本地化用途，正文和资源目录在宿主技能加载工具成功调用后返回。
- `luaskills-packages` 发行资产仍需要 Lua 模块与运行时包的帮助索引。这些文件属于[运行时打包布局](../integration/ffi-integration-guide.md)，与技能包的旧帮助接口独立。
- 各语言 SDK 跟随核心 `0.9` 系列，安装同系列中契约摘要匹配的最新已发布补丁。见 [SDK 版本规则](../sdk/index.md#版本规则)。

## 运行时变化

- 加载时会记录并跳过损坏的包，其他包继续加载。高优先级的包即使加载失败也保留其标识的遮蔽关系。安装、更新失败会回滚，启用失败会保留原有生效状态。
- 依赖先暂存再原子发布。清理会保留正在使用的依赖根，以及同一宿主数据目录下仍由其他生效技能层使用的共享记录。
- 执行截止时间覆盖 Lua 与受支持的阻塞宿主操作，包括进程 I/O、Python/Node 调用、环境构建及等待锁。脚本捕获中间异常后，超时的执行仍以失败结束。不可中断的原生调用在真实返回前继续持有租约。见[执行截止时间契约](../../../contracts/system-lease-execution.md)。
- FFI 边界捕获 panic，并限制过深的值嵌套。Rust 1.99.1 的原子操作已迁移至新版标准库接口。
