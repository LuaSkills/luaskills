# 受管 Python 与 Node.js 运行时版本升级计划

## 任务目标

将 LuaSkills 主仓与 Python、TypeScript、Go 三个 SDK 的受管运行时默认版本统一升级到当前稳定组合：Python 3.14.4、uv 0.11.28、Node.js 24.18.0 LTS、pnpm 11.11.0，并同步代码、脚本、示例、测试和多语言文档。

## 详细执行步骤

1. 以 Python/uv/Node.js/pnpm 官方发布信息确认精确稳定版本及平台资产可用性。
2. 更新主仓下载脚本、布局校验器、真实示例、依赖清单、Rust 测试夹具和多语言文档。
3. 更新三个 SDK 的默认常量、资产计划测试、中英文 README 与随包脚本。
4. 保证主仓和三个 SDK 的 PowerShell、POSIX shell、Python 校验脚本语义一致。
5. 在 Windows x64 真实下载并校验 Python、uv、Node.js、pnpm，执行 smoke 与布局检查。
6. 运行主仓与三个 SDK 的格式、静态检查、全量测试和发布包检查。
7. 连续五轮审核无问题后追加执行总结并归档计划。

## 技术选型

- 固定精确版本保证可复现，不在运行时静默跟随上游最新版本。
- Node.js 选择当前最新 LTS 24.18.0，不选择 Current 26.x。
- Python 选择 uv 当前提供跨平台便携构建的最新稳定 3.14.4，不选择 3.14.5 RC。
- uv 与 pnpm 使用当前最新稳定发布 0.11.28 与 11.11.0。

## 验收标准

- 四个仓库不再把旧版本作为当前默认值或当前示例。
- `dependencies.yaml`、下载脚本、SDK 常量和 README 精确一致。
- Windows x64 真实运行时拉取、版本输出、布局检查和 smoke 通过。
- 主仓及三个 SDK 全量验证通过。
- 最终连续五轮审核无问题。
